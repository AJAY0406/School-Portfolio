## Getting Started

### Prerequisites

- Node.js **20.9 or later** (Node.js 22 LTS recommended)
- npm (included with Node.js)

### Run locally

```bash
npm install
npm run dev
```

Open **http://localhost:3000** in your browser.

### Test the production build

```bash
npm run build
npm run start
```

> On Windows, if `npm` is not recognized, install Node.js and restart VS Code. If PowerShell blocks `npm.ps1`, try `npm.cmd install` and `npm.cmd run dev`.

## Customize the Portfolio

- **Personal details, project descriptions, links, skills, and education:** edit `app/page.tsx`.
- **Colors, spacing, animations, and layout:** edit `app/globals.css`.
- **Images:** replace files in `public/images/`, or change the image paths in `app/page.tsx`.
- **Certificates:** `public/images/certificate-pmi.png` and `public/images/certificate-python.png`.

Review your contact information and certificate images before publishing them publicly.

## Deploy to Vercel

1. Run `npm run build` locally and resolve any errors.
2. Create a GitHub repository and push the **project files** (not the ZIP archive). Keep `node_modules`, `.next`, and secrets out of Git.
3. Visit **https://vercel.com/new** and import the GitHub repository.
4. Choose the **Next.js** framework preset. If `package.json` is in the repository root, leave **Root Directory** as `./`.
5. Select **Deploy**. Vercel will provide a public `*.vercel.app` URL after a successful build.

Future pushes to the connected GitHub branch will trigger new deployments automatically.
